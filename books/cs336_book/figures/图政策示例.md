## 3. 转换规则（M1 逐章执行）

1. **先判信息密度**：一页幻灯片如果只有 1–2 行字 + 一个公式/一句结论 → 转文字，不留图。
2. **再判是否是结构**：箭头、框、层次、张量形状 → 重绘 SVG；重绘时必须用幻灯片原有术语，不得自创概念。
3. **数据图保留**：折线/柱状/散点带上数值与出处，一律 `keep`，并在图注写「数据来自 X，原图」。
4. **视频帧一律丢**：关键帧只在正文需要「说明这里有一段演示」时用一句话代替。
5. **每张图必须能溯源**：`figure_policy.csv` 的 `src` 列 + 转换产物路径；重绘图在 SVG 里写明「依据 lecture_03.pdf p11–p12 重绘」。

## 4. 与「前置知识」的配合

图不是装饰：每张 `text+svg` 页转写后，要落进对应知识单元（`evidence/chapterNN/Uxx-*.yaml`）的 `knowledge_slot`，否则就是无归属的素材。
