# RSI 教材配套小实验

本目录的实验只依赖 Python 3 标准库，不需要 GPU、模型 API、第三方包或下载数据。

## 覆盖率与验证器误差

在工作区根目录运行：

    python source/labs/coverage_demo.py

程序固定随机种子 20261021，比较候选数增加时的理论覆盖率、模拟覆盖率和最终选中准确率。默认参数为单个候选正确率 5%、验证器灵敏度 90%、假阳性率 10%、每种候选数运行 40,000 轮。

读者应当自己改动 P_CORRECT、VERIFIER_SENSITIVITY 和 VERIFIER_FALSE_POSITIVE_RATE，记录输出，再解释三条曲线为什么会分开。这个实验只演示“生成候选—评估选择”闭环；候选生成算法和更新算法固定，因此它本身不构成严格意义上的递归自我改进。

## 反复筛选与留出评估

在工作区根目录运行：

    python source/labs/selection_overfit_demo.py

程序生成一组训练样本和独立留出样本，并反复生成候选权重，只按训练集误差选择候选。训练数据中的干扰特征与目标偶然相关，留出数据中则不相关。比较候选数增加时的训练误差与留出误差，说明为何多轮选择会过拟合训练数据，以及何时需要独立评估。候选生成规则和选择程序保持固定，所以该实验用于理解筛选偏差，不是完整 RSI。
