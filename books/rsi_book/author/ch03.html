第 3 章　模型侧自改进：自训练、RLAIF 与可验证奖励

本章讨论更新模型可训练参数 \(\theta\) 的自我改进方法。案例包括自训练（STaR）、基于 AI 反馈的训练（Constitutional AI）、模型评审与偏好优化（Self-Rewarding）、可验证奖励强化学习（RLVR/GRPO）以及 DAPO。各方法使用的目标函数、反馈和数据生成方式不同。本书以样本如何获得训练权重及其依据作为比较维度，并分别保留各论文原有定义。

更新对象

本章主要分析模型可训练参数 \(\theta\) 的更新。除非论文另有说明，讨论中将提示模板、数据管道、脚手架和评估程序视为固定条件；相关实验结论仅适用于其报告的模型、数据与评测协议。

3.1 模型更新目标与反馈信号

对于基于当前策略采样的策略梯度方法，设 \(q\) 为提示，\(o\) 为模型生成，\(\pi_\theta\) 为当前策略。模型使用奖励或优势信号更新策略参数，其 score-function 梯度可表示为

\[ \nabla_\theta J(\theta) = \mathrm{E}_{q,\,o \sim \pi_\theta}\big[ A(q,o)\nabla_\theta \log \pi_\theta(o \mid q) \big]. \]

式中 \(A(q,o)\) 表示奖励或优势信号。不同算法在 token 级奖励分配、基线估计、参考策略约束和梯度裁剪等方面采用不同设计。监督微调通常通过最大化训练样本的条件似然更新模型；拒绝采样微调使用筛选后的样本进行训练。DPO 采用基于偏好样本对的直接优化目标，其目标函数与策略梯度形式不同（Rafailov et al., arXiv:2305.18290）。PPO 使用优势估计形成策略梯度更新；DeepSeekMath 提出的 GRPO 利用组内奖励构造相对优势估计，无需单独训练价值网络。这些方法在训练数据、目标函数和参数更新机制上存在差异，需要分别分析。

统一记号的适用范围。以下表示用于比较样本权重和反馈来源，各方法保留各自的训练目标与优化机制。SFT 的训练期望基于给定数据集，GRPO 则涉及策略生成的样本；两者的估计偏差、梯度方差和优化性质需要分别讨论。DPO 采用直接偏好优化目标，应与策略梯度方法区分。比较 STaR 与 GRPO 时，应分别考察样本筛选机制、优势估计、目标函数和数据生成过程。

记号 3-1

本章以 \(\pi_\theta\) 表示当前更新的策略，以 \(\pi_{\text{old}}\) 表示采样阶段使用的冻结策略；\(r(q,o)\) 表示标量奖励，在二元可验证奖励设置中可由答案正确性确定；\(A_t\) 表示第 \(t\) 个 token 的优势。序列级奖励均摊到 token 时记为 \(A_{i,t}=A_i\)。

3.2 STaR：自举推理链（2022）

STaR（Self-Taught Reasoner，arXiv:2203.14465）是早期具有代表性的模型侧迭代自训练方法。其训练过程包括三个主要步骤：(i) 对训练集中的题目生成推理链和答案；(ii) 将答案正确的推理链加入微调数据；(iii) 对初次作答错误的题目，将标准答案提供给模型，要求模型生成能够导出该答案的推理链。通过筛选的样本用于更新 \(\pi_\theta\)，随后进入下一轮生成和筛选。

该方法的答案筛选采用二元答案匹配标准，其适用性取决于任务能否可靠判定答案正确性。对于初次作答错误的样本，rationalization 可增加训练数据，但生成过程可能依据已知答案构造事后解释，不能单独证明模型掌握了可靠的推理机制。按判据 2-1，该设置属于一阶更新：筛选规则、提示模板和微调流程预先设定，迭代中主要更新模型参数 \(M\)。

论文报告，6B GPT-J 经 STaR 训练后在 CommonsenseQA 上达到 72.5%，与该论文所列 GPT-3 微调结果 73.0% 接近。消融实验显示，移除 rationalization 后该设置的表现下降。论文还分析了题目暗示答案和循环论证等失效模式；这些观察说明生成的推理链需要独立验证。

3.3 Constitutional AI：宪法原则与 AI 反馈训练（2022）

RLHF 的一项成本来自逐条收集人类偏好标注。Constitutional AI（CAI，arXiv:2212.08073）使用书面行为原则（例如拒绝有害请求并避免说教）指导两阶段训练。在监督阶段，模型依据原则批评并修订自身回答（SL-CAI），修订结果用于监督微调；在强化阶段，模型依据原则比较回答并生成偏好标签，以训练评审模型，再通过 RLAIF（RL from AI Feedback）进行优化（RL-CAI）。该流程减少了部分训练环节对逐条人工偏好标注的依赖；原则制定、流程设计和结果评估仍可能涉及人工。

因此，Constitutional AI 改变的是偏好反馈的生成方式，并未消除人工对原则、训练流程和评估标准的设定。若反馈模型与被改进模型共享训练来源或偏差，训练结果可能继承这些偏差；第 7 章讨论相应的评估风险。

3.4 Self-Rewarding：模型生成偏好评审（2024）

Self-Rewarding Language Models（arXiv:2401.10020）将模型生成与模型评审纳入迭代训练。模型使用 LLM-as-a-Judge 评估生成结果，形成偏好数据，再进行迭代式 DPO。作者报告，Llama-2 70B 经三轮训练后，在 AlpacaEval 2.0 上超过论文所列的 Claude 2、Gemini Pro 与 GPT-4 0613 基线。该结果适用于论文使用的模型、数据和评测设置；它不单独证明生成能力提升会使自评准确性同步提高。

作者指出该方法仍有局限，并将真实场景中的持续改进列为开放问题。论文报告的 AlpacaEval 2.0 评估使用外部评审模型；这一设置不能直接确定使用同一模型评审时的结果。自评偏差、训练数据变化和评测器依赖均可能影响迭代效果，需要在相应的实验设置中单独检验。

3.5 RLVR 与 GRPO：可验证奖励强化学习（2024）

DeepSeekMath（arXiv:2402.03300）在数学推理实验中使用规则可验证奖励：奖励在最终答案与标准答案匹配时取 \(r_i=1\)，否则取 \(r_i=0\)，不需要单独训练奖励模型。该论文提出 GRPO（Group Relative Policy Optimization），使用同一问题下多条采样回答的组内奖励构造相对优势，省去单独训练的 critic。该方法仍包含策略优化目标和正则化设计，不能简化为仅从 PPO 中删除 critic：

\[ \hat{A}_{i,t} = \widetilde{r}_i = \frac{r_i - \operatorname{mean}(r)}{\operatorname{std}(r)}, \]

其中 \(r=(r_1,\dots,r_G)\) 是针对同一题 \(q\) 生成的一组 \(G\) 个回答的奖励。GRPO 使用组内均值作为基线，不另训练价值网络；其目标仍包含 PPO 裁剪和 KL 正则（完整形式见 DeepSeekMath 式 (3)）。DeepSeekMath 论文报告了该方法在 MATH 和 GSM8K 上的结果，以及与自洽采样和训练前模型的比较。RLVR（RL with Verifiable Rewards）后来被用于描述以可验证信号训练强化学习系统的研究路线；不同工作使用的任务、奖励定义和训练设置并不相同。

按照 3.1 节的比较维度，GRPO 使用在线采样和组内标准化优势，STaR 主要依据答案正确性筛选生成样本。两者在反馈利用方式、优化目标和数据更新机制上均有差异，不存在由此可推出的严格算法包含关系。

3.6 DAPO：面向 RLVR 训练的算法设计（2025）

DAPO（arXiv:2503.14476，字节跳动与清华大学）报告了 Qwen2.5-32B 基座在 AIME 2024 上的实验结果，并公开了相应训练实现。论文提出四项算法设计，用于处理 RLVR 规模化训练中的不同问题：

技术失效模式处方
Clip-Higher（解耦裁剪上下界）裁剪范围可能限制低概率 token 的更新单独设置较宽的上裁剪界 \(\varepsilon_{\text{high}}\)
Dynamic Sampling组内奖励相同的题目不提供区分性优势信号过采样后保留组内奖励有差异的题目
Token-Level 损失序列级平均对不同长度回答的 token 赋权不同按有效 token 归一化损失
Overlong Reward Shaping超长截断可能产生不适当的惩罚信号对超长回答设置渐进奖励，并处理截断部分的梯度

动态采样会优先保留组内奖励存在差异的题目，使这些样本在当前训练批次中提供区分性反馈。奖励方差会影响策略梯度信号，但训练效果还取决于采样分布、优化目标和模型状态。自动生成任务与任务时间地平线测量回答的是不同问题，不应据此视为同一机制。

3.7 模型侧的边界：什么进了权重，什么没进

STaR、Self-Rewarding、GRPO 与 DAPO 都在任务之间更新模型参数；它们的提示模板、采样设置、数据管道和奖励程序通常由实验者设定。由此可见，模型更新的效果受这些固定设计与评估条件限制。程序验证能够提供可复核的判分，但只覆盖程序实际检查的属性；模型评审也可能带来偏差。第 5、6 章讨论系统代码和改进流程成为更新对象时，评估器与独立测试的设计。

本章小结与思考题

本章按反馈与更新方式比较了自训练、AI 反馈、模型评审和可验证奖励强化学习。相关论文报告了各自在特定模型、数据集和评估协议上的结果；这些结果不能直接外推到其他任务。模型参数虽可由训练过程更新，训练目标、数据来源和验收协议仍通常由实验者设定。
