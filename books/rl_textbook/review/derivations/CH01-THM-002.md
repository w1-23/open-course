# CH01-THM-002：(1.16) 的信息量对象取错——用 I(θ;·) 得不到 H(A*) 这一步

对象：`content/ch01.md` 第 228 行（信息比定义与 I_T）与第 230–234 行（式 (1.16)）

```
记 I_T = I(θ; h_{T+1}) 为历史对参数的信息量，并定义信息比
Γ_t = (E[Δ_t])² / I(θ; A_t, r_t | h_t) …… 得
Regret‾(T) ≤ √(Γ̄ T I_T) ≤ √(Γ̄ T H(A*)) ≤ √(Γ̄ T ln K).            (1.16)
```

## 1. 链式法则那一步是对的

`Γ_t` 的定义给出 `(EΔ_t)² = Γ_t · I(θ; A_t, r_t | h_t)`，于是

```
(Σ_t EΔ_t)² ≤ T Σ_t (EΔ_t)²                                    (Cauchy–Schwarz)
            ≤ T Γ̄ Σ_t I(θ; A_t, r_t | h_t)
            = T Γ̄ I(θ; h_T)                                     (互信息链式法则)
```

所以 `Regret‾(T) ≤ √(Γ̄ T I_T)` 在 `I_T = I(θ; h_T)` 的定义下成立。

## 2. 第二步不成立

式 (1.16) 接着写 `I_T ≤ H(A*)`。**这一步与 `I_T` 的定义不相容**：`I(θ; h_T)` 是
"历史对**参数**的信息量"，它可以远大于 `H(A*)`。反例（同一个 Bandit，K = 2）：

- 先验 `θ ~ U(0,1)²` 连续，`A* = 1{θ_1 > θ_2}`，故 `H(A*) = H(1/2) = ln 2 ≈ 0.69` nats；
- 策略轮流采样两臂，`Q_t` 是样本平均。`I(θ; h_T)` 随样本量增长：两臂各拉 n 次时，
  每臂的均值被估到 `O(1/√n)`，`θ` 的可辨识区间收缩，`I(θ; h_T) → ∞`（`T → ∞`）。

于是 `I(θ; h_T) ≤ ln K` 显然为假，`√(Γ̄ T I_T) ≤ √(Γ̄ T ln K)` 这一步失去依据；
`I_T` 越大，最后那个界反而越"松"，而式 (1.16) 却把它当上界用。

## 3. 正确写法：信息量的对象是最优动作，不是参数

Russo 与 Van Roy 的界（TS 教程式 (8.7)、(8.8)，
`source/pages/1707.02038_thompson-sampling/p0079.txt`、`p0080.txt`）是

```
Γ_t = (E[μ(x*, θ) − μ(x_t, θ)])² / I(x*; (x_t, y_t) | H_{t−1}),
E[Regret(T)] ≤ √(Γ · H(x*) · T),        Γ = max_t Γ_t.
```

分母是 **`x*`（最优动作）**与即将到来的观测之间的互信息，不是 `θ`。这样链式法则给出的是
`Σ_t I(x*; (x_t,y_t)|H_{t−1}) = I(x*; h_T) ≤ H(x*)`——**互信息不超过被判定的那个离散随机
变量的熵**，这才是 `≤ ln K` 能成立的原因（`H(x*) ≤ ln K` 只需 `x*` 有 K 个取值）。

教程同页还写明该界对任意模型与算法成立，且 `H(x*)` 一项正是"先验知识带来收益"的体现
（`p0081`：`H(x*)` 不超过动作数目的对数，先验越明确越小）。

## 4. √(KT ln K) 的来路

有了正确的界，`√(Γ H(x*) T)` 要变成 `√(KT ln K)` 还需要 `Γ = O(K)`（K 臂情形下
`θ` 是 K 维的，教程给出的对角例子是 `Γ ≤ d/2`，`p0080`、`p0081`）。
正文第 236 行"共轭情形下它的信息比有界，从而得到 √(KT ln K) 量级"里的"有界"若指与 K
无关的常数，则只能得到 `√(T ln K)`；若要 `√(KT ln K)`，必须写成"信息比 ≤ K/2 量级"。
这一处属**表述不完整**，与第 2 节的错误分开处理。

## 5. 修法

1. 把 `I_T` 与 `Γ_t` 的信息量对象从 `θ` 改为 `A*`：`I_T = I(A*; h_{T+1})`、
   `Γ_t = (EΔ_t)² / I(A*; A_t, r_t | h_t)`；
2. 在 (1.16) 的说明句里写清"链式法则给 `I(A*; h_T)`，它不超过 `H(A*)`"；
3. 第 236 行把"信息比有界"补成"信息比 `O(K)` 量级（K 臂情形下 `Γ ≤ K/2`）"；
   若暂无本地源支持 `K/2`，就只写量级而不给具体常数。
