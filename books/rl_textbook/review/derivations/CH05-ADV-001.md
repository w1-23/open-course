## 1. 基线恒等式

对离散动作、`b` 只依赖状态：

```
E_{a~π(·|s)}[ ∇log π(a|s) · b(s) ]
  = Σ_a π(a|s) · [∇π(a|s)/π(a|s)] · b(s)
  = b(s) Σ_a ∇π(a|s)
  = b(s) ∇ ( Σ_a π(a|s) )
  = b(s) ∇1 = 0
```

关键是 `b` 能提到 `Σ_a` 之外。若 `b` 依赖动作（`b(s,a)`），则

```
Σ_a ∇π(a|s) b(s,a) ≠ 0   （一般情形）
```

因为 `b(s,a)` 不能提出求和号，`Σ_a π(a|s) = 1` 这条恒等式就用不上了。
**结论：条件恰是"b 不随动作变化"，与 Sutton & Barto 第 329 页的表述一致，不需要有界性。**

## 2. 蒙特卡洛版本（式 5.11）为什么无偏

取 `b(s) = V_φ(s)`、权重用从 `(s_t,a_t)` 出发的真实回报 `G_t`：

```
E[ G_t − V_φ(s_t) | s_t=s, a_t=a ] = Q^π(s,a) − V_φ(s)
```

把它代回占用测度形式的梯度：

```
Σ_a ∇π(a|s) · ( Q^π(s,a) − V_φ(s) )
  = Σ_a ∇π(a|s) Q^π(s,a) − V_φ(s) Σ_a ∇π(a|s)
  = Σ_a ∇π(a|s) Q^π(s,a)          （第二项由第 1 节恒等式为零）
```

右端正是 ∇J 的被加项，与 `V_φ` 是否准确**无关**。这就是本章命题 B 的完整依据，
也是第 182 行"只要求基线不依赖动作，不要求 critic 精确"的确切含义。

## 3. 自举版本（式 5.15）为什么会有偏

一步 AC 用的是 `δ_t = r + γV_φ(s') − V_φ(s)`。取条件期望：

```
E[δ_t | s_t=s, a_t=a] = R(s,a) + γ Σ_{s'} P(s'|s,a) V_φ(s') − V_φ(s)
```

记 `Q^{V_φ}(s,a) := R(s,a) + γ Σ_{s'} P(s'|s,a) V_φ(s')`，则

```
E[δ_t | s,a] = Q^{V_φ}(s,a) − V_φ(s)
```

代回同样的推导，第二项仍为零，但第一项变成 `Σ_a ∇π(a|s) Q^{V_φ}(s,a)`，而真梯度是
`Σ_a ∇π(a|s) Q^π(s,a)`。两者之差

```
Σ_a ∇π(a|s) [ Q^π(s,a) − Q^{V_φ}(s,a) ] = γ Σ_a ∇π(a|s) Σ_{s'} P(s'|s,a)[V^π(s') − V_φ(s')]
```

**一般不为零**——因为 `V_φ` 的误差经过转移核 `P(·|s,a)` 之后**依赖动作**了。
这就是 GAE 原文第 4 页"only γ-just for V = V^{π,γ}, otherwise it will yield biased
policy gradient estimates"的实质，也是本章 5.2.3 节"λ<1 时自举把 V_φ 的误差乘进优势"
的根据。

**因此"用 V_φ 当基线不引入偏差"只对蒙特卡洛版本（式 5.11）成立；对自举版本（式 5.15）
不成立。** 本章第 182 行把命题 B 明确绑在式 (5.11) 上，这一点是对的；风险在于第 136 行
"选择 b=V_φ …… 代价是引入一点偏差"没有说明"偏差在优势估计、不在梯度期望"，读者会把
它与命题 B 读成矛盾，或反过来以为一步 AC 也无偏。

## 4. 与 GAE 原文的层次对照

| 估计量 | 权重 | 期望 | 偏？ |
|:--|:--|:--|:--|
| 式 (5.11)，b=V_φ，MC 回报 | G_t | ∇J（精确） | 无偏（任意 V_φ） |
| 式 (5.15)，一步 δ | δ_t | 用 Q^{V_φ} 代替 Q^π | V_φ≠V^π 时有偏 |
| GAE，0<λ<1 | Σ(γλ)^l δ | 自举项带 V_φ 误差 | 有偏，随 λ→1 减小 |
| GAE，λ=1 | Σγ^l δ = G_t−V_φ | 第 2 节 | 无偏（任意 V_φ） |

这张表就是"两个命题 + λ<1 有偏"的统一解释，建议在修订时以一句话形式写进 5.2.3。

## 5. 数值旁证

`figures/ch05_figs.py` 的 `_chain_policy_gradient` 在 4 状态链式 MDP 上给出解析梯度，
第 5 章图 5-3 用"精确 critic"与"放大 1.6 倍的错误 critic"分别估计梯度：错误 critic 在
λ=0 时偏差 0.18、λ=1 时降到 0.02（只剩采样噪声），精确 critic 两端都在噪声量级。
这与第 2、3 节的结论一致：**λ=1 抹掉了自举偏差，λ=0 把 critic 误差经 P 传成动作相关的偏差。**
