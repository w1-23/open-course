# CH05-GAE-001 推导与核对记录

对象：`content/ch05.md` 第 220–244 行（式 5.17、5.18 与第 238 行的"偏差"表述）。

## 1. 望远镜求和：λ=1 时恰好是 G_t − V_φ(s_t)

从一步 TD 误差 `δ_t = r_t + γV_φ(s_{t+1}) − V_φ(s_t)` 出发，前 k 项加权和：

```
Â^(k)_t = Σ_{l=0}^{k−1} γ^l δ_{t+l}
        = Σ_{l=0}^{k−1} γ^l r_{t+l}
          + Σ_{l=0}^{k−1} γ^l ( γV_φ(s_{t+l+1}) − V_φ(s_{t+l}) )
```

第二行内部相邻项相消（`γ^{l+1}V_φ(s_{t+l+1})` 与 `γ^{l+1}V_φ(s_{t+l+1})` 抵消），只剩
两端：

```
= Σ_{l=0}^{k−1} γ^l r_{t+l} − V_φ(s_t) + γ^k V_φ(s_{t+k})
```

令 `k → ∞`（γ<1 使 `γ^k V_φ → 0`）：

```
lim_{k→∞} Â^(k)_t = Σ_{l≥0} γ^l r_{t+l} − V_φ(s_t) = G_t − V_φ(s_t)
```

即本章式 (5.18)。**这一步只用到"γ<1 且 V_φ 有界"，不要求 V_φ = V^π。**

## 2. GAE 的几何权重

GAE(γ,λ) 定义为各 k 步估计的指数加权平均：

```
Â^GAE_t = (1−λ) Σ_{k≥1} λ^{k−1} Â^(k)_t
```

把 `δ_{t+l}` 的系数整理出来：`δ_{t+l}` 出现在所有 `k ≥ l+1` 的项中，权重为
`(1−λ)Σ_{k≥l+1} λ^{k−1} γ^l = γ^l λ^l`，所以

```
Â^GAE_t = Σ_{l≥0} (γλ)^l δ_{t+l}
```

即本章式 (5.17)，与 GAE 原文式 (16) 相同。两个端点：

- λ=0：`Â = δ_t`（原文式 17）；
- λ=1：几何权重全为 1，回到第 1 节的望远镜求和，`Â = G_t − V_φ(s_t)`（原文式 18）。

## 3. "偏差"的三种来源

| 来源 | 何时为零 | 本章是否写了 |
|:--|:--|:--|
| 自举偏差（用 V_φ 代替 V^π 进入 δ） | λ=1，或 V_φ=V^π | 写了（第 238 行"λ<1 时…偏差出现"） |
| 折扣偏差（γ<1 相对未折扣目标） | γ=1 | **未写**（原文 p.5 明确列出） |
| 采样偏差（有限样本、on-policy 假设） | 无穷样本且 on-policy | 部分（5.5 节提到评估协议） |

第一种是本章讨论的对象：λ<1 时 `V_φ` 的误差经转移核 `P(·|s,a)` 变成**动作相关**的项，
于是梯度期望偏离 ∇J（推导见 `CH05-ADV-001.md` 第 3 节）。λ=1 时该误差只剩 `−V_φ(s_t)`，
是纯状态函数，在梯度里被"Σ_a ∇π = 0"消掉，故**λ=1 时偏差与 V_φ 的精度无关**——这与原文
"GAE(γ,1) is γ-just regardless of the accuracy of V"一致。

第二种是本章的盲区：本章式 (5.1) 把折扣写进目标本身（`J = E[Σγ^t r]`），因此不存在
"相对未折扣目标的偏差"；而 GAE 原文把 γ 当作**未折扣问题**上的方差削减参数，γ<1 在那里
确实引入偏差。**两套写法各自自洽，但不能互相套用**；本章若不说明，读者拿本章的
"λ=1 无偏"去对照原文的"γ<1 有偏"会以为其中一处写错。

## 4. 数值核对

`figures/ch05_figs.py` 在 4 状态链式 MDP（γ=0.9）上测得（30 次重复 × 80 条轨迹）：

| critic | 偏差（λ=0 → λ=1） | 标准差（λ=0 → λ=1） |
|:--|:--|:--|
| 精确 V^π | 0.0019 → 0.0068（噪声量级） | 0.0136 → 0.0402 |
| 放大 1.6 倍的错误 V_φ | 0.1844 → 0.0182 | 0.0904（λ=0）→ 0.0402（λ=1） |

与第 3 节一致：错误 critic 的偏差随 λ 单调降到噪声量级，标准差随 λ 上升。

## 5. 与原文 p.4 那句"otherwise biased"的调和

原文第 4 页说 δ^V "only γ-just for V = V^{π,γ}, otherwise it will yield biased policy
gradient estimates"。这句话针对的是**自举形式**（λ=0 及 0<λ<1）；本章命题 B 针对的是
**蒙特卡洛权重** `G_t − V_φ(s_t)`（式 5.11）。两者不矛盾，但需要在正文里点明：

- 用 `G_t` 当权重：任意 `V_φ` 都不改变梯度期望（命题 B）；
- 用 `δ_t` 当权重：`V_φ ≠ V^π` 时自举项把误差变成动作相关项，梯度有偏；
- GAE 在两者之间插值：λ 越大，自举项权重 `(γλ)^l` 衰减越慢，偏差越小、方差越大。

## 结论

- 式 (5.17)、(5.18) 与原文式 (16)(17)(18) 完全一致，"λ=1 偏差与 critic 精度无关"正确；
- 缺"折扣偏差"一层，属内容缺项；
- 与原文 p.4 的表面冲突只需要一句"MC 权重 vs 自举权重"的分层说明。
