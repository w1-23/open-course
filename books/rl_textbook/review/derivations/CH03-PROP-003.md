# CH03-PROP-003：n 步回报的"偏差与方差介于两端"是趋势，不是定理

对象：`content/ch03.md` 第 253–262 行「3.4.1 n 步回报」，第 262 行：

```
中间取值的偏差与方差介于两端：用到的真实奖励越多，自举成分越少，偏差越小、方差越大。
```

## 1. 问题

这句话把两件事混成一句断言：

1. **偏差随 \(n\) 单调下降**——这一条可以严格证明（见第 2 节，本质是 \(\gamma^n\) 收缩），是 [精确]。
2. **方差随 \(n\) 单调上升**——这一条**一般没有**，只是常见趋势。

正文没有给这句话标理论地位，读者会默认两条都成立。审查时这是可被判错的地方（"偏差—方差权衡不单调"）。

## 2. 偏差一条确实严格

S&B 的 n 步误差缩减性质（p.166，式 (7.3)）：

\[
\max_s\bigl|\mathbb{E}_\pi[G_{t:t+n}\mid S_t=s]-v^\pi(s)\bigr|\le\gamma^n\max_s\bigl|V_{t+n-1}(s)-v^\pi(s)\bigr|,\qquad \forall n\ge1.
\]

即"用当前估计 \(V\) 自举的 \(n\) 步回报，其期望与真值的差 ≤ \(\gamma^n\) 倍的当前误差"。所以偏差的上界按 \(\gamma^n\) 收缩，\(n\) 越大上界越小——这一条是精确的（在给定 \(V\) 的前提下）。

顺带说明为什么这条不能直接推广到方差：它约束的是**期望**（对 \(S_t=s\) 条件），完全没说二阶矩。

## 3. 方差一条为什么不单调

\(G^{(n)}_t=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}+\gamma^nV(S_{t+n})\)，其方差可以拆成

\[
\operatorname{Var}(G^{(n)}_t)=\operatorname{Var}\Bigl(\sum_{k<n}\gamma^kR_{t+k+1}\Bigr)+2\sum_{k<n}\gamma^{k+n}\operatorname{Cov}\bigl(R_{t+k+1},V(S_{t+n})\bigr)+\gamma^{2n}\operatorname{Var}(V(S_{t+n})).
\]

- 若奖励之间、奖励与自举值之间都独立非负相关，第一项随 \(n\) 单调增，方差大致随 \(n\) 增——这是教材默认的情形（随机游走、无折扣）。
- 但第三项前的交叉项可以**为负且量级不小**：例如"最近拿到大奖励的状态，其价值估计反而低"这种结构（奖励与状态价值负相关），或 \(\gamma<1\) 时 \(\gamma^{2n}\) 把自举项压得很快。此时 \(\operatorname{Var}(G^{(n)})\) 可以随 \(n\) 先降后升、甚至非单调。

构造一个最小的反例形状：两状态确定性交替任务，\(R\) 在一个状态恒为 \(+1\)、另一个恒为 \(0\)，且两状态价值估计被固定成 \(V(s_0)=0,\ V(s_1)\gg0\)。则 \(n=1\) 时 \(G^{(1)}=1+\gamma V(s_1)\) 几乎无方差（确定性），\(n=2\) 时 \(G^{(2)}=1+\gamma\cdot0+\gamma^2V(s_0)=\text{const}\)，而 \(n=3\) 引入更长视野的随机性后方差回升——方差序列不是单调的。

## 4. 结论与修正

- 偏差：**单调不增的上界**（式 7.3），标 [精确]。
- 方差：**通常**随 \(n\) 增大（视野更长、随机源更多），但不是定理；应标 [经验规律]，并补一句"存在奖励与自举值负相关时方差非单调的情形"。
- 正文第 262 行建议改为："用到的真实奖励越多，自举成分越少，偏差的上界按 \(\gamma^n\) 收缩 [精确]；方差通常随之增大，但这一条只是趋势而非定理 [经验规律]——它取决于奖励与自举值的相关性。"

## 5. 与 3.4.2 节的关系

3.4.2 节说"\(\lambda\) 增大使长 \(n\) 步回报的相对权重变大"，这是权重层面的事实（与方差单调性无关），不受本条影响；但 3.4.2 节"步长大时靠较小的 \(\lambda\) 抑制方差"的经验解释，其依据正是"方差随 \(n\) 增"这一趋势——补上 [经验规律] 的标签后，这句话才不会被读成定理。
