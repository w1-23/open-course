# CH01-THM-004：式 (1.10) 标 [渐近]，与本章第 8 行的标签定义相冲突

对象：`content/ch01.md` 第 157 行（定理 1.2 的标签）与第 167 行（作者自述）

```
::: thm 定理 1.2（UCB1 的对数遗憾 [渐近]）
```
```
关于标签要诚实：式 (1.10) 严格说对每个有限 T 都成立，地位其实是 [精确]；
标 [渐近] 是因为它的可读内容只有"遗憾按 ln T 增长"这一件事。
```

## 1. 本章自己给出的标签定义

第 8 行：

> 标 **[精确]** 的结论对每个有限 `T` 成立，标 **[渐近]** 的只描述 `T → ∞` 的曲线形状，
> 其余标 **[经验规律]**；每个界都与它的常数和前提一起出现。

按这个定义，判定一个标签只需问一句："它对每个有限 `T` 成立吗？"式 (1.10) 是
`Regret(T) ≤ 8 Σ ln T/Δ_a + (1+π²/3) Σ Δ_a`，两侧都含 `T`，且不等式对每个 `T ≥ 1` 成立
（这是 UCB 类分析的有限时域结论；"只差 `log T` 因子"的说法也正是对**有限 T** 界而言，
见 `source/pages/1904.07272_bandit-algorithms/p0017.txt` 的 "Optimality" 段）——因此按第 8 行
它应标 `[精确]`。

## 2. 冲突点

第 167 行作者自己承认"地位其实是 `[精确]`"，但定理框仍标 `[渐近]`。这不是数学错误，
而是**章内两处口径不一致**：读者按第 8 行的方法判读，会得到一个与定理框相反的结论。
同一章对 `[渐近]` 的另外两处用法（式 (1.3) 的 `liminf`、第 58 行的极小极大讨论）是符合
定义的，于是 (1.10) 成了唯一的不一致点。

## 3. 作者的理由为什么不成立

作者的理由是"可读内容只有按 `ln T` 增长这一件事"。但"可读内容"是**叙述**层面的判断，
而标签在本书里是**陈述的强度**标记（第 8 行："每个界都与它的常数和前提一起出现"）。
用标签去提示"这条界别当真"，会让标签失去可比性：读者无法再把"标 `[精确]`"当作
"对每个有限 `T` 成立"来用。把"这条界的常数不可当数值保证"放进正文句子（第 167 行已经
写了），比改标签更合适。

## 4. 建议改法

- 定理框改标 `[精确]`（界对每个有限 `T` 成立）；
- 保留第 167 行的诚实说明，但改为"常数 `8` 与 `1+π²/3` 是证明的产物，换个置信界就换一组
  常数，别当数值保证用"，删去"地位其实是 `[精确]`，标 `[渐近]` 是因为……"这一段——
  既然标签已改，这段自我辩解就不需要了；
- 若坚持 `[渐近]`，则须在第 8 行补一条"内容比标签弱时以内容为准"的例外规则，否则本章
  的标签体系不自洽。

  near-optimal … optimal up to O(log T) factors"，说明这类界的可读性正是"有限 T 上只差
