# CH03-ALG-301：算法 3-1 的收敛判据恒为真

对象：`content/ch03.md` 第 46–58 行「算法 3-1 策略迭代（表格型）」，第 53 行

```
6:     V(s) ← v；Δ ← max(Δ, |v - V(s)|)
```

## 1. 问题

同一行内先把 `V(s)` 赋成 `v`，再用 `|v − V(s)|` 算差，赋值后 `V(s) == v`，
因此 `|v − V(s)| = 0` 恒成立，`Δ` 永远是 0，循环条件 `Δ < θ` 在第 1 次扫描后就满足。

后果不是"慢一点"，而是**算法变了**：
- 评估阶段永远只做 1 次扫描，所谓"评估到足够准"从未发生；
- 返回的 `V` 不是 `V^π`（只是一次备份的结果），第 42 行"误差压到 θ 所需扫描次数
  ≈ log(θ/‖V₀−V^π‖)/log γ"的讨论与代码不符；
- 若读者照抄，会在需要 `V^π` 的地方（如策略改进的 `Q^π`、后续 Actor-Critic 的
  基线）拿到错误的价值。

## 2. 权威写法

S&B 第二版，pdf p.102（§4.3 策略迭代算法，第 3 步之前的策略评估）：

```
3. Policy Evaluation
   ...
   v ← V(s)
   V(s) ← Σ_{s',r} p(s',r | s, π(s)) [ r + γ V(s') ]
   Δ ← max(Δ, |v − V(s)|)
until Δ < θ
```

关键在 `v ← V(s)` 这行：**先用副本 `v` 保存旧值，再更新 `V(s)`，最后用 `v` 与
`V(s)` 求差**。本书的伪代码漏掉了这一步的顺序。

（同一算法在书中 4.1 节的"迭代策略评估"里也是这个顺序，`Δ` 一定取自更新前的值。）

## 3. 修正

```
5:     对每个 s：v ← Σ_a π(a|s) Σ_s' P(s'|s,a)[r + γ V(s')]
6:     Δ ← max(Δ, |v - V(s)|)；V(s) ← v
```

即把两条语句交换顺序；或者保留一行，但改成"先算差再赋值"的写法。

## 4. 数值确认

`review/reproductions/CH03-ALG-301_fix.py`：5×5 网格世界（目标 +1、两处 −1、每步 −0.04、
γ=0.9、θ=1e-6），两种写法各跑完整策略迭代：

| 写法 | 策略迭代轮数 | 评估扫描总数 | 最后一轮扫描 | V(0,0) |
|:--|--:|--:|--:|--:|
| Δ 在赋值之后（书中现状） | 12 | 12 | 1 | **−0.040000** |
| Δ 用旧值（S&B 写法） | 8 | 723 | 9 | **0.269616** |

错误写法每轮只扫 1 次（总数 12 = 12 轮 × 1 次），且最终 `V(0,0)` 与正确值差 0.31。
注意它仍可能收敛到最优**策略**（因为单次备份 + 立即改进近似值迭代），所以只看策略
是发现不了的——这正是"静默错误"的典型形态。

## 5. 表述层面

第 44 行"有限状态下…严格单调的改进序列必然在有限步内停在…"这段论证本身正确（定理 2.5
保证逐状态不劣 + 至少一个严格改进 ⇒ 策略集合单调），但它依赖"评估到足够准"；改成
`Δ` 正确之后，这句与代码才一致。同时应把"评估到收敛"改成"评估到 `Δ < θ`"，明确是
截断评估而非精确评估（与 3.1.3 一节的 `m` 次扫描口径对齐）。
