## 1. 未归一化占用测度的总质量

定义（本章式 5.5）

```
d^π_γ(s) = Σ_{t≥0} γ^t Pr_π(s_t = s | s_0 ~ ρ0)
```

对 s 求和并交换求和次序：

```
Σ_s d^π_γ(s) = Σ_{t≥0} γ^t Σ_s Pr_π(s_t = s) = Σ_{t≥0} γ^t · 1 = 1/(1−γ)
```

第二個等号用到"给定 t，s_t 有某个取值"这一必然事件；第三個等号是几何级数（γ<1）。
**结论：总质量 1/(1−γ)，与本章第 57 行一致。**

归一化版本

```
d̄^π_γ(s) = (1−γ) d^π_γ(s),   Σ_s d̄^π_γ(s) = 1
```

## 2. 式 (5.6) 与式 (5.7) 只差一个因子

从式 (5.6) 出发（对动作求和写成期望）：

```
∇J = Σ_s d^π_γ(s) Σ_a ∇π(a|s) Q^π(s,a)
   = Σ_s d^π_γ(s) Σ_a π(a|s) [∇π(a|s)/π(a|s)] Q^π(s,a)
   = Σ_s d^π_γ(s) Σ_a π(a|s) ∇log π(a|s) Q^π(s,a)
```

代入 d^π_γ = d̄^π_γ/(1−γ)：

```
∇J = (1/(1−γ)) Σ_s d̄^π_γ(s) Σ_a π(a|s) ∇log π(a|s) Q^π(s,a)
   = (1/(1−γ)) E_{s~d̄^π_γ, a~π} [ ∇log π(a|s) Q^π(s,a) ]
```

即本章式 (5.7)。**因子恰为 1/(1−γ)，没有别的常数。**

反向验证：若把式 (5.7) 里的 1/(1−γ) 丢掉，得到的是 (1−γ)∇J，方向相同、尺度差
(1−γ)；这与"把常数吸进学习率"不同——学习率只改变步长，不改变被优化的目标，而这里
改变的是梯度与目标之间的比例关系，一旦同时使用裁剪阈值、KL 阈值或熵系数，标定就全错。

## 3. 原始文献的同一步换算

TRPO（1502.05477）第 4 页把"对状态的求和"换成"对分布的期望"时写的是

```
Σ_s ρ_θold(s) [...]  →  (1/(1−γ)) E_{s∼ρ_θold} [...]
```

其中 ρ_θold 在第 2 页被明确定义为 `(unnormalized) discounted visitation frequencies`。
这与本 card 第 2 节完全同构：**未归一化求和 ↔ 归一化期望之间必须补 1/(1−γ)**。
本章式 (5.6)/(5.7) 的写法因此不是自创记号，而是与原始文献一致的两种等价表述。

## 4. 与第 2 章的冲突

第 2 章式 (2.8) 写作 `d^π_γ` 但取的是归一化版本（总质量 1）。本章第 61 行已点明
"第 2 章的式 (2.8) 用的是归一化版本但仍写作 d^π_γ"，并在本章一律用 `d^π_γ` 表示
未归一化、`d̄^π_γ` 表示归一化。**同一符号在相邻两章指不同对象**，这是全书层面的
记号问题，不是本章的推导错误；修法见 card 的 planned_fix 第 2 条（需 lead 决策）。
