# CH01-THM-001：(1.10) 的常数 8 只对应 c = √2，而正文让 c 自由、实验用 c = 2

对象：`content/ch01.md` 第 146–149 行（式 (1.9)）与第 157–165 行（定理 1.2 与式 (1.10)）

```
A_t = argmax_a { Q_t(a) + c√(ln t / N_t(a)) },  c > 0            (1.9)
::: thm 定理 1.2（UCB1 的对数遗憾 [渐近]）
设 K 个臂的奖励独立同分布、取值于 [0,1]……则 UCB1 的期望遗憾满足下面的界。
:::
Regret(T) ≤ 8 Σ_{a:Δ_a>0} ln T/Δ_a + (1+π²/3) Σ_a Δ_a            (1.10)
```

## 1. 索引里 c 是自由参数，界里却是固定常数

式 (1.9) 把 c 写成 `c > 0` 任意，第 151 行还明确说"c 是置信水平的手柄"；而式 (1.10)
的常数 `8` 是一个具体数字。两者要能同时成立，必须 `8` 与 (1.9) 里那个 c 对得上。
下面把标准分析逐行算一遍，看它对 c 的依赖。

## 2. 一般 c 的遗憾分析

设次优臂 a 的间隙 `Δ_a = μ* − μ_a > 0`，`Q_t(a)` 是已观测奖励的样本平均，
`n = N_t(a)`。索引

```
U_t(a) = Q_t(a) + c·√(ln t / n).
```

在时刻 t 选了 a（且 n = N_t(a)）时，至少下面三件之一成立：

1. **高估**：`Q_t(a) ≥ μ_a + c√(ln t/n)`；
2. **低估最优臂**：`Q_t(a*) ≤ μ* − c√(ln t/n)`（因为 U_t(a) ≥ U_t(a*) 且 U_t(a*) ≥ Q_t(a*)）；
3. **必然情形的计数约束**：`μ_a + 2c√(ln t/n) ≥ μ*`，即 `n ≤ 4c² ln t / Δ_a²`。

（1）由 Hoeffding 与 `n` 个独立样本：[0,1] 有界奖励下

```
P(Q_t(a) − μ_a ≥ ε) ≤ exp(−2nε²),
```

取 `ε = c√(ln t/n)` 得 `P(1) ≤ exp(−2c² ln t) = t^(−2c²)`。（2）同理。
于是对任意 T：

```
E[N_T(a)] ≤ 4c² ln T / Δ_a² + 1 + 2 Σ_{t≥1} t^(−2c²),
```

尾部级数收敛当且仅当 `2c² > 1`，即 `c > 1/√2`。乘以 Δ_a 并对 a 求和：

```
E[Regret(T)] ≤ 4c² Σ_{a:Δ_a>0} ln T/Δ_a + (1 + 2Σ_t t^(−2c²)) Σ_a Δ_a.        (*)
```

**首项常数是 4c²**，不是与 c 无关的 8。

## 3. 8 对应哪个 c

令 `4c² = 8`，得 **c = √2**。这个取值不是巧合：Auer 等 (2002) 的 UCB1 原版置信半径是
`r_t(a) = √(2 ln t / n_t(a))`，即 (1.9) 中 `c = √2`；Lattimore 与 Szepesvári 的书把它写成
`r_t(a) = √(α ln t / n_t(a))` 并注明 `α = 2`（`source/pages/1904.07272_bandit-algorithms/p0017.txt`，
印 p.13，式 (1.15) 及其脚注）。所以

- `c = √2`：(*) 的首项 = `8 Σ ln T/Δ_a`，与 (1.10) 一致；
- `c = 2`（**本章表 1-2 的实验设定**，第 255 行"UCB1（式 (1.9) 取 c=2）"）：首项应为
  `4·4 = 16 Σ ln T/Δ_a`，(1.10) 的 8 不成立；
- `c ≤ 1/√2`：尾部级数发散，(*) 不成立，且索引已不再是有效上置信界（此时算法可退化为
  近似贪心，线性遗憾）。

## 4. 结论

定理 1.2 的表述是"对 (1.9) 定义的 UCB1，遗憾 ≤ (1.10)"。由于 (1.9) 里 `c > 0` 自由，
这句话对 `c = 2`（正是本章实验用的值）是**假**的：正确的首项常数是 16 而不是 8。
命题成立的正确条件是把它写成"取 `c = √2` 的 UCB1"或把 (1.10) 写成 `4c² Σ ln T/Δ_a`
（并补 `c > 1/√2`）。

## 5. 三种修法（供 planned_fix 选择）

A. **最省事**：在 (1.9) 后加一句"本节固定 `c = √2`（即 Auer 等 2002 的 `√(2 ln t/N)`）"，
   并删掉"c > 0"的任意性表述；实验段把 `c = 2` 改成 `c = √2` 或注明实验与定理用的不是同一 c。
B. **保留一般性**：把 (1.10) 的首项常数改成 `4c²`，并在定理前提里补 `c > 1/√2`。
C. **分开写**：定理只陈述 `c = √2` 的经典形式，另用一句说明"乘以 c² 得到一般 c 的界"。
