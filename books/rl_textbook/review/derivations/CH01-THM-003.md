# CH01-THM-003：Θ(√(KT)) 的归因把上下界两侧混在一起

对象：`content/ch01.md` 第 58 行（1.1.3 节末段）

```
极小极大界先在实例类上取上确界，对 [0,1] 有界奖励类的最优量级是 Θ(√(KT))（Auer 等 2002）
```

## 1. 一处归因承载了三件事

这句话实际用了三个断言：

1. `[0,1]` 有界奖励类的极小极大遗憾是 `Ω(√(KT))`（下界）；
2. 存在算法达到 `O(√(KT))`（上界）；
3. 这两件事都由 Auer 等 (2002) 给出。

(1)(2) 合起来才是 `Θ`。(3) 才是需要核对的部分。

## 2. Auer 等 (2002) 给的是"差一个 log T"的上界

Lattimore 与 Szepesvári（`source/pages/1904.07272_bandit-algorithms/p0017.txt`，印 p.13，
"Optimality" 段）写道：

> Regret bounds in (1.9) and (1.11) are near-optimal, according to the lower bounds which we
> discuss in Chapter 2. The instance-dependent regret bound in (1.9) is optimal up to O(log T)
> factors. **Audibert and Bubeck (2010) shave off the log T factor**, obtaining an instance
> dependent regret bound O(√(KT)).

也就是说：UCB 家族的经典界是"只差 `O(log T)` 因子"的近似最优，把 log 因子去掉、得到
`√(KT)` 阶是 Audibert 与 Bubeck (2010) 的工作。把 `Θ(√(KT))` 整体署名给 2002 年的那篇，
等于把 2010 年的那一半也算进去了。

同页还给出 UCB1 半径的原始形式（式 (1.15)，`α = 2`），正是"2002 年版"的代表。

## 3. 风险在哪

这里不是纯学术署名问题：正文用这句话支撑"`√(KT)` 与 `ln T` 并不矛盾——取 sup 的顺序不同"
的论点（第 171 行结尾又用了一次）。读者若按"2002 年就有匹配的上下界"去查文献，会发现
2002 年的上界是 `√(KT log T)`，从而怀疑整段论证。正确的写法应当把两侧分开署名。

## 4. 建议改法

> 对 `[0,1]` 有界奖励类，极小极大遗憾的阶是 `Θ(√(KT))`：`√(KT)` 阶下界由 Auer 等 (2002)
> 给出，匹配的上界在 2010 年前后由 Audibert 与 Bubeck 等通过去掉 `log T` 因子得到。

若只保留一句，则写"Auer 等 (2002) 的 UCB 界只差一个 `log T` 因子，与 `Ω(√(KT))` 的下界
共同确定量级"。

## 5. 待核验
