# 推导：CH11-GRPO-001 —— 组内相对优势不是"与动作无关的基线"

本文件是证据卡 `review/cards/CH11-GRPO-001.yaml` 的 `derived_claim` 支撑材料。
结论先行：**把组均值 `r̄` 当成"动作无关、因此只改方差"的基线是错的**；它给出的是
一个按 `(1 − 1/G)` 缩放的策略梯度估计，而再除以组标准差 `s_r` 是非线性变换，
一般不存在"期望不变"的结论。三层表述见文末。

---

## 1. 设定与记号

固定一个问题（prompt）`q`，从旧策略采样 `G` 个独立输出

```
o_1, ..., o_G  ~  i.i.d.  π_old(· | q)
r_i = r_φ(q, o_i)            （奖励模型对整条输出打分，确定性函数）
r̄  = (1/G) Σ_j r_j           （组均值，注意它含 r_i 本身）
s_r = sqrt( (1/G) Σ_j (r_j − r̄)^2 )   （组标准差，同样含 r_i）
Â_i = (r_i − r̄) / s_r         （DeepSeekMath 式 (4.1.2) 的 outcome 版本）
```

策略梯度里与 `o_i` 相关的项记作

```
g_i := E[ r_i ∇_θ log π_θ(o_i | q) ]        （未加基线的一步梯度）
```

其中期望对 `o_1..o_G` 的采样取。`∇ log π` 指整条序列的对数概率梯度
（token 级求和的写法不影响下面结论，见 §5）。

---

## 2. 基线恒等式为什么要求"与动作无关"

对**不依赖 `o_i`**的量 `b`（常数、或只依赖状态/问题 `q` 的量），有

```
E[ b ∇ log π(o_i) ] = b Σ_o ∇π(o) = b ∇Σ_o π(o) = b ∇1 = 0 .
```

这就是"S&B p.359：把状态价值函数当基线可降低方差而不引入偏差"的全部内容
（来源见卡片 `c1`）。它的前提是 `b` 在给定状态下是**常数**，而不是同一组里
另一个随机样本的函数。

---

## 3. 组均值实际给出什么

把 `r̄` 代进去，用线性性拆开：

```
E[(r_i − r̄) ∇log π(o_i)]
  = E[r_i ∇log π(o_i)] − (1/G) Σ_j E[r_j ∇log π(o_i)]
```

逐项看：

* `j = i`：`E[r_i ∇log π(o_i)] = g_i`。
* `j ≠ i`：`r_j` 与 `o_i` 独立（同组独立采样），且 `r_j` 不依赖 `o_i`，于是
  `E[r_j ∇log π(o_i)] = E[r_j] · E[∇log π(o_i)] = E[r_j] · 0 = 0`。

因此

```
E[(r_i − r̄) ∇log π(o_i)] = g_i − (1/G) g_i = (1 − 1/G) · g_i .        (★)
```

**读法**：自包含组均值不是"零效应基线"，而是把每次梯度**按 `1 − 1/G` 缩小**。
`G = 1` 时 `(★)` 为 0——一个样本的"组内相对优势"恒等于 0，这也说明它不是基线；
`G = 8` 时缩到 `0.875`。

`(★)` 的两点后果：
1. **方向不变**：`(1 − 1/G) > 0`，所以它仍是上升方向，实践中"能用"。
2. **步长变了**：等价于把学习率乘 `(1 − 1/G)`；若把它写成"不改变期望、只降方差"，
   就把缩放误当成了偏差消除。

---

## 4. 除以 `s_r` 之后：没有一般性"期望不变"

`Â_i` 还除以 `s_r`，而 `s_r` 是同一组样本的函数，与 `r_i` 相关。于是

```
E[ (r_i − r̄)/s_r · ∇log π(o_i) ]  ≠  (1/s_r 的某个常数) × g_i
```

一般不能把 `1/s_r` 提出期望（`s_r` 与分子不独立），这是典型的**比率估计量**问题：
其偏差一般是非零的 `O(1/G)` 量级，只在 `G → ∞` 且 `s_r` 依概率收敛到某个正数时，
才可作渐近论证（此时 `s_r` 可近似视为常数，退化为 `(★)` 再乘一个标量）。

因此：**在有限 `G` 下，`Â_i` 既不是无偏策略梯度，也不是"无偏但换了个基线"**；
可主张的只有"是一个带缩放的、方差较小的上升方向"。

数值上可验证：取 `G = 8`、`r ~ Bernoulli(p)` 的玩具模型，用 Monte Carlo 估
`E[Â_i ∇log π]` 与 `(1 − 1/G) g_i`，差值随 `1/G` 减小而不为零。复现脚本见
`review/reproductions/CH11-GRPO-001_mc.py`（待写）。

---

## 5. 长度归一化（token 级）再加一层依赖

DeepSeekMath 目标里对 token 求平均 `1/|o_i|`，且同一输出的所有 token 共享
`Â_i`（outcome supervision）。于是单 token 的权重含 `1/|o_i|`，而 `|o_i|` 与
`o_i` 相关——这会引入"长度—奖励"耦合，是后续工作讨论长度偏好的入口
（见 `c3`，Dr. GRPO 的分析；该文属 P2 研究材料，只进研究框，不作定理依据）。

---

## 6. 可以写进教材的三层表述

| 层 | 表述 | 前提 | 标签 |
|:--|:--|:--|:--|
| ① | 若基线 `b` 只依赖 state/prompt，不依赖被采样的动作，则 `E[b∇log π]=0`，减去它不改变期望 | 分数函数恒等式成立（`π_θ > 0` 于支撑集） | [精确] |
| ② | 自包含组均值 `r̄` 不是这种基线：`E[(r_i−r̄)∇log π(o_i)] = (1−1/G)g_i`，是把梯度缩小的估计 | 组内独立同分布、`G ≥ 2` | [精确] |
| ③ | 再除以 `s_r` 并做 `1/|o_i|` 平均后，有限 `G` 下偏差一般非零，只在 `G → ∞` 有渐近论证；实践中的收益与组大小、归一化方式、动态采样相关 | 比率估计量、非渐近 | [经验规律] |

**禁止表述**（写进正文的硬约束）：
* "组均值与动作无关，因此式 (11.12) 只改变方差"——`(★)` 已否证；
* "GRPO 的组内归一化优势是无偏策略梯度"——§4 已否证；
* "GRPO 就是 PPO 去掉 critic"——漏掉组采样、组内归一化、token 共享与长度归一化。
