## 1. 本书自己的贝尔曼式是对的

式 (9.3) 取"选项内一步后可能终止"的形式：

```
Q(s,o) = Σ_{s'} P(s'|s,o) [ r + γ ( (1 − β_o(s')) Q(s',o) + β_o(s') V(s') ) ]
```

对 `β_o(s')` 求偏导时，`V(s')` 与 `(1−β_o(s'))Q(s',o)` 都含 `β_o(s')`，两项合并恰好得到

```
∂Q(s,o)/∂β_o(s') = P(s'|s,o) · γ · [ Q(s',o) − V(s') ]        … (9.4)
```

**结论：式 (9.4) 的系数、符号与括号内两项都是正确的**，且括号内正是"进入 s' 后继续该选项
相对于换选项的优势"。此前审查报告曾把它列为"方向错误"，此处予以撤回。

## 2. 原始定理（Bacon, Harb & Precup, AAAI 2017，pdf p.3）

**Theorem 1（Intra-Option Policy Gradient Theorem）**

```
∂J/∂θ = Σ_{s,ω} μ_Ω(s,ω|s0,ω0) Σ_a ∂π_{ω,θ}(a|s)/∂θ · Q_U(s,ω,a)
```

其中 `Q_U` 是**原始动作级**的动作价值，`μ_Ω` 是 state-option 对的折扣占用测度
`μ_Ω(s,ω|s0,ω0) = Σ_t γ^t P(s_t=s, ω_t=ω | s0,ω0)`。

**Theorem 2（Termination Gradient Theorem）**

```
∂J/∂ϑ = − Σ_{s',ω} μ_Ω(s',ω|s1,ω0) · ∂β_{ω,ϑ}(s')/∂ϑ · A_Ω(s',ω),
        A_Ω(s',ω) = Q_Ω(s',ω) − V_Ω(s')
```

关键点有三：
1. 优势的两项**都在 s'**（被测终止函数的那个状态），不是"一个在 s、一个在 s'"；
2. 定理里**没有显式的 γ 乘子**，γ 已被吸收进 `μ_Ω` 的折扣加权；
3. 梯度对 `ϑ` 是**负号**（提高终止概率在优势为负时才划算，与本书正文的直觉一致）。

## 3. 与「算法 9-1」逐行对照

原文第 6–7 行（`content/ch09.md`，算法框内）：

```
6:    theta <- theta + eta_theta * grad_theta log pi_o(a|s) * Q(s,o; w)
7:    beta  <- beta + eta_beta * gamma * (Q(s,o; w) - V(s'; w)) * grad_beta beta_o(s')
```

| 行 | 问题 | 依据 |
|:--|:--|:--|
| 7 | `Q(s,o) − V(s')` 两项的**评估状态不一致**：定理 2 要求 `Q_Ω(s',ω) − V_Ω(s')`。用 `Q(s,o)` 相当于把"进入 s' 后的优势"错写成"当前状态的选项价值"，选项越长偏差越大 | Theorem 2, p.3 |
| 7 | 显式 `gamma` 乘子不是定理 2 的一部分（γ 在 `μ_Ω` 里）。保留它是把它当作**步长尺度**，必须写明"这里把 γ 并入步长"，否则会被读成与定理一致 | Theorem 2, p.3 |
| 6 | 定理 1 的梯度权重是 `Q_U(s,ω,a)`（原始动作价值），书中用 `Q_Ω(s,o)`。仅当"选项内策略在一个选项步内固定、且以 state-option 对为更新单位"时二者可互替；否则是近似 | Theorem 1, p.3 |
| 全 | 伪代码没有写"β 用 sigmoid 松弛、否则梯度不存在"，也没有写终止正则/最小选项长度，读者按字面实现会遇到"每个选项只持续一步" | 书中 §9.1.2 末段已述，但伪代码未带条件 |

## 4. 修改后应当写成什么

```
6:    theta <- theta + eta_theta * grad_theta log pi_o(a|s) * Q_U(s,o,a; w)
7:    beta  <- beta - eta_beta * (Q(s',o; w) - V(s'; w)) * grad_beta beta_o(s')
      备注：定理 2 无显式 gamma；若把 gamma 并进步长，须在正文说明
8:    以概率 beta_o(s') 终止，否则 s <- s' 继续
```

同时正文需要补两句：
- 式 (9.4) 是"对 β_o(s') 的单步偏导"，把它变成策略梯度定理还要乘占用测度并对 τ 取期望，
