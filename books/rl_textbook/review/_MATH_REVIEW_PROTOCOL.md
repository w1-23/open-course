# 数学审校协议（MATH_REVIEW）

> 目的：把 `review/math_review.yaml` 里的 `pending` 变成有据可查的判定。
> 不是"再过一遍眼"，而是逐条回答三个问题：**这个式子成立需要什么前提、书上有没有写、
> 结论的标签（精确／渐近／近似／经验规律）与证明强度是否匹配。**

## 0. 硬约束

1. **只读 `content/`，不改正文**。发现缺陷写进报告，由 lead 决定是否施工。
2. **不编造**。判断"这个定理在文献里是这样说的"之前，必须先看
   `source/pages/<key>/pNNNN.txt` 的原文；引文从该文件复制，不得转写 LaTeX。
3. 拿不准就写 `blocked` 并列出待核验项，**不要**为了凑"通过"而放过。
4. 每个式子都要给判定，不许只抽样结论。抽样只允许用于"与文献比对"这一步。

## 1. 输入

- 正文：`content/chNN.md`（`NN` 为章号；导航章是 `ch00.md`，预备章是 `ch13prep.md`，编号前缀 `P`）
- 证据卡：`review/cards/CHNN-*.yaml`（已有卡片的章，卡片里的 `claims` 就是已知争议点）
- 一手文献：`source/pages/<key>/pNNNN.txt`（用 `python scripts/search_sources.py "关键词"` 检索）
- 章节来源映射：`source/source_map.yaml`

## 2. 逐式检查的五项（每项给 ✓ / ✗ / 不适用）

对 `\tag{N.k}` 的每一个式子：

| 项 | 检查什么 |
|:--|:--|
| **P 前提** | 式子成立所需的前提（有限性、折扣、平稳性、满列秩、on-policy、独立同分布…）是否在同一节的前文里写明 |
| **S 符号** | 式中的符号是否都在符号表（附录 A）或本节定义过；同一字母在本章是否一符多义而未澄清 |
| **L 标签** | `[精确]`／`[渐近]`／`[近似]`／`[经验规律]` 是否与证明强度一致（等式且对一切对象成立才可 `[精确]`） |
| **D 推导** | 式与上一式之间的那一步是否成立（换序、取期望、求导、放缩各查一次）；推不出来记 ✗ 并写出你认为缺的那一步 |
| **U 用途** | 后文引用它时是否用对了方向（把界当等式、把渐近当有限样本、把必要条件当充分条件） |

## 3. 与文献比对（每题至少 3 式）

优先核对"结论性"公式：Bellman 方程、算子与误差界、策略梯度、重要性比率、离线保守项、
BT 似然、DPO 重参数化、GRPO 归一化。

- 在 `source/pages/` 里找到对应原文，**逐字复制**一段（≥25 字符）作为 `quote`；
- 记录 `source_key` 与 `pdf_page`；
- 若书中写法与原文不同（换符号、加折扣、改常数为变量），必须判断是**等价改写**还是**不一致**；
  不一致记 ✗ 并在报告里给出原文与书稿的对照。

## 4. 输出

### 4.1 报告 `review/math_review/CHNN.md`

```markdown
# 第 N 章 数学审校

审校人：<你的名字>　日期：2026-10-21　结论：reviewed | blocked

## 1 逐式判定

| 式号 | P | S | L | D | U | 备注 |
|:--|:-:|:-:|:-:|:-:|:-:|:--|
| 7.1 | ✓ | ✓ | ✓ | ✓ | ✓ | |

## 2 与文献比对

| 式号 | 文献 | 页 | 原文片段 | 判定 |
|:--|:--|:--|:--|:--|

## 3 缺陷清单（blocked 时必填）

1. `content/chNN.md:行号` — 问题 — 建议改法 — 证据

## 4 无法核实项
```

### 4.2 片段 `review/math_review/CHNN.yaml`

```yaml
'no': 7
status: reviewed          # 或 blocked
reviewer: author-ch4（独立审校）
reviewed_at: '2026-10-21'
equations: ['7.1', '7.2', '7.3']      # 必须与 md 里 \tag 的顺序一致、数量相同
primary_sources: ['1504.06833_pets', 'RLbook2020']
notes: 一句话说明重点核了什么、留了什么
```

预备章用 `'no': 95`，`equations` 写 `P.1`…`P.9`。导航章 `'no': 0`。

## 5. 判 `reviewed` 的门槛

以下三条全部满足才可以写 `reviewed`：

1. 该章每一个 `\tag` 都有逐式判定，且没有未解释的 ✗；
2. 至少 3 个结论性公式与 `source/pages/` 原文比对过，并在报告里留下 `quote`；
3. 报告第 3 节要么为空，要么只剩"已记录但按现状保留"的说明（由 lead 批）。

否则写 `blocked`，第 3 节列全缺陷，lead 会据此决定施工。

## 6. 自检命令

```bash
python scripts/check_math.py                 # 记录完整性（只查字段与覆盖，不查推导对错）
python scripts/verify_quotes.py --only N     # 若你在卡片里新增了引文
python check_refs.py --only N                # 确认你没把式号引错
```
