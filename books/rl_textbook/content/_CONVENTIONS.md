## 1. 状态空间与任务

- 有限状态空间记 `𝒮`，一般状态空间记 `S`；动作空间 `𝒜`／`A`。同一推导内不得混用两种记号。
- 转移核 `P(s'|s,a)`；奖励 `R_{t+1}` 或 `r(s,a)`，**同一推导内不得混用**。
- 折扣 `0 ≤ γ < 1`；除非章节明确讨论有限时域或平均奖励，否则默认无限时域折扣。
- 折扣回报 `G_t = Σ_{k≥0} γ^k R_{t+k+1}`。

### 1.1 三种目标的并列写法（不得混写）

| 目标 | 价值定义 | 贝尔曼方程 | 状态分布 |
|---|---|---|---|
| 无限时域折扣 | `V^π(s)=E_π[G_t∣S_t=s]` | `V^π = r^π + γP^πV^π` | `d^π_γ`，总质量 `1/(1−γ)` |
| 平均奖励 | `V^π(s)=E_π[Σ_t (R_{t+1}−ρ(π)) ∣ S_0=s]` | `V^π + ρ(π) = r^π + P^πV^π` | 平稳分布 `d^π`，总质量 1 |
| 有限时域 | `V^π_t(s)`，带 `t` 下标 | `V^π_t = r^π + γP^πV^π_{t+1}`，`V^π_H=0` | 按层定义 |

写平均奖励时必须改用 `J_avg` 或 `ρ(π)`，**不得**沿用折扣 `J` 而不说明。

### 1.2 终止与截断（强制）

- **terminated**：MDP 本身进入终止状态 → `V(terminal)=0`，自举**停止**。
- **truncated**：因时间上限、采样预算或系统条件中断 → 自举**继续**，用 mask 保留 bootstrap。
- 不得把两者都置 `done=1`；伪代码中必须分别出现 `terminated` 与 `truncated`。

## 2. 策略、价值与优势

- 策略 `π(a|s)`；行为策略 `μ(a|s)`（`μ` 不再同时表示均值）。
- `V^π(s)=E_π[G_t∣S_t=s]`，`Q^π(s,a)=E_π[G_t∣S_t=s,A_t=a]`，`A^π(s,a)=Q^π(s,a)−V^π(s)`。
- 最优量统一加 `*`：`V^*`、`Q^*`、`π^*`。
- **估计量必须带参数下标或帽**：`V_φ`、`Q_φ` 是估计，**不得当作真值**；`Â` 必须加帽。
- 参数约定：`θ` = actor/policy 参数；`φ` = critic/value 或 reward-model 参数（除非局部明确重定义）。

## 3. 策略目标与占用测度

```
目标：      J(θ) = E_{s0~ρ0}[ V^{πθ}(s0) ]                     （ρ0 与折扣目标都不可省）

未归一化：  d^π_γ(s) = Σ_{t≥0} γ^t Pr_π( s_t = s | s0 ~ ρ0 )，  Σ_s d^π_γ(s) = 1/(1−γ)
归一化：    d̄^π_γ(s) = (1−γ) d^π_γ(s)，                          Σ_s d̄^π_γ(s) = 1

梯度两种等价写法（同一个 J）：
  ∇_θ J = Σ_s d^π_γ(s) Σ_a π_θ(a|s) ∇_θ log π_θ(a|s) Q^π(s,a)
  ∇_θ J = 1/(1−γ) · E_{s~d̄^π_γ, a~π_θ}[ ∇_θ log π_θ(a|s) Q^π(s,a) ]
```

- 换用 `d̄` 时 `1/(1−γ)` **必须保留**；只有把目标改成 `(1−γ)J` 才能省掉它（并须显式说明）。
- 「把常数吸进步长」**不能**替代上式中的严格等式。

## 4. TD 与资格迹

- `δ_t = R_{t+1} + γV(S_{t+1}) − V(S_t)`。
- `λ ∈ [0,1]`。`n` 步回报 `G^{(n)}_t = Σ_{k=0}^{n−1} γ^k R_{t+k+1} + γ^n V(S_{t+n})`。
- `G^λ_t = (1−λ) Σ_{n≥1} λ^{n−1} G^{(n)}_t`（`0 ≤ λ < 1`）。**λ 增大使权重衰减变慢、长 n 步回报相对权重变大，不是各权重趋于相等**——全稿禁用"权重摊平"这一说法。有限回合用含终止余项的有限时域定义。
- **`γ` 与 `λ` 不得合并称作同一种"衰减系数"**：`γ` 定义任务目标，`λ` 调节多步/自举混合。
- 真在线 TD（true online TD(λ)）只进延伸阅读，不占正文。

## 5. 函数逼近

- 线性价值函数 `v_θ = Φθ`；`Φ` 满列秩。加权范数 `‖v‖²_D = vᵀDv`。
- `D` = 由指定状态分布决定的加权对角矩阵；**数据集用 `𝒟`**，两者不得混用。
- 投影 `Π_D = Φ(ΦᵀDΦ)^{-1}ΦᵀD`，**必须声明**依赖线性函数空间与满列秩。
- **三个 Bellman 误差是不同对象，符号与语义都不得互换**：
  - Bellman residual `‖T^πv_θ − v_θ‖`；
  - MSBE `‖T^πv_θ − v_θ‖²_D`；
  - MSPBE `‖Π_D T^π v_θ − v_θ‖²_D`（线性情形 `(Aθ−b)ᵀC^{-1}(Aθ−b)`，`C=ΦᵀDΦ`）。
- 深度 Q-learning 实际优化的是**采样平方 TD 误差**，又是另一个对象。

## 6. 策略梯度与 PPO

- 基线恒等式：对任意不依赖当前动作的 `b(s)`，`E_{a∼π}[∇logπ(a|s)b(s)] = b(s)∇Σ_aπ(a|s) = 0`。
- 优势估计**不是天然无偏**。必须区分两个命题：
  - (i) **优势估计无偏**：`E[G_t − V_φ(s_t) ∣ s_t,a_t] = Q^π(s_t,a_t) − V_φ(s_t)`；**只有 `V_φ = V^π` 时才等于 `A^π`**。
  - (ii) **策略梯度估计无偏**：`V_φ(s_t)` 是动作无关的基线，即使 critic 不精确，在正确 on-policy 采样等条件下策略梯度期望仍可不变。
- GAE：`Â^{GAE(γ,λ)}_t = Σ_{l≥0} (γλ)^l δ^V_{t+l}`；`λ<1` 时自举引入偏差；PPO 的裁剪再叠一层近似。
- `ρ_t(θ) = π_θ(a_t|s_t) / π_old(a_t|s_t)`；`ε_clip` 专指 PPO/GRPO 裁剪，**与数值稳定 `ε_num` 分开**。
- **PPO 是近似工程算法，clip ≠ 信赖域保证**；正文必须写"动机来自 TRPO，实现上放弃了硬 KL 约束"。

## 7. 熵、KL 与温度

- `H(π) = −E_π[log π]`；`D_KL(p‖q) = E_p[log(p/q)]`，**方向必须写出，不允许只写"KL"**。
- SAC 用 `α_ent` 表示熵温度，**不与学习率 `α` 共用**。
- 语言模型 KL 正则系数 `β_KL > 0`：
  `max_π E_π[r] − β_KL D_KL(π‖π_ref)`；Gibbs 最优策略
  `π^*(y|x) ∝ π_ref(y|x) exp(r(x,y)/β_KL)`。
- 在指数形式中 `β_KL` 同时充当**温度**，`1/β_KL` 是**逆温度**；**不得写成"温度 1/β"**。若所引论文采用相反参数化，首次引用时显式换算。

## 8. On-policy / Off-policy

- behavior policy 记 `μ`，target policy 记 `π`；重要性比率 `ρ_t = π(A_t|S_t)/μ(A_t|S_t)`。
- "off-policy"表示**数据生成策略与目标策略不同**，**不等同于"使用了 replay buffer"**。
- 支持集条件：目标策略的支持集必须包含于行为策略（或参考策略）的支持集，否则重要性权重不可定义。

---

## 9. 风险与安全（第 9 章）

- 一律以**损失变量** `Z`（越大越坏）为约定；对收益定义的风险度量方向相反，引用时必须显式转换。
- `VaR_α(Z) = inf{ z : Pr(Z ≤ z) ≥ α }`，`α ∈ (0,1)` 是**水平**（不是概率、不是置信度）。
- `CVaR_α(Z) = inf_{η∈ℝ}{ η + 1/(1−α) E[(Z−η)_+] }`；连续无原子时 `= E[Z ∣ Z ≥ VaR_α(Z)]`，取**上尾**。
- **CMDP 约束期望**，CVaR 约束**尾部统计量**，二者不可互换。

## 10. GRPO（第 11 章）

- `G` = 同一 prompt 的 completion 数；`r_1,…,r_G`；`r̄ = 1/G Σ r_j`，`s_r = sqrt(1/G Σ (r_j−r̄)²)`。
- `Â_i = (r_i − r̄)/(s_r + ε_num)`；`ε_num` **只是数值保护，不是理论定义的一部分**；`s_r = 0` 的组 mask 掉。
- token 级 surrogate：
  `1/G Σ_i 1/|o_i| Σ_t min[ρ_{i,t}Â_i, clip(ρ_{i,t},1−ε_clip,1+ε_clip)Â_i] − β_KL·KL`。
- **必须写明**：`Â_i` 是同 prompt 样本间的**相对奖励信号，不等于 learned `A^π(s,a)`**；序列级奖励下同一 completion 的 token 共享 outcome advantage，**credit assignment 很粗**。

## 11. 公式状态标签（强制）

每个定理、命题、误差界、复杂度结论必须在句末标注以下之一：

- `[精确]`：在写明的假设下严格成立；
- `[渐近]`：只在极限/大样本/小步长下成立；
- `[近似]`：由某个近似替换得到，须写明被替换的量；
- `[经验规律]`：由实验观察归纳，不构成定理。

**深度 RL 算法在没有定理支持时，不得使用无条件的"收敛""稳定"**；应写"在……设置下经验上稳定"。

### 11.1 理论分层铁律

```
Tabular  ≠  Linear FA  ≠  Nonlinear FA  ≠  LLM policy optimization
```

表格型的收敛条件（无限次访问 + 步长条件）**不得**直接搬给 DQN；线性 TD 的投影固定点理论**不得**直接解释神经网络 TD；PPO `clip` **不是**信赖域保证；GRPO 的组标准化优势**不是**学习出来的 `V^π` 的无偏替代。
